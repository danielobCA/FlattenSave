# Changelog

All notable changes to [FlattenSave](https://github.com/donajello/FlattenSave).

## 1.0.3

### New
- **Settings window** — click the cog in the panel header to:
  - set an export hotkey (one to three keys)
  - show the full file path in the preview
  - export to extra formats at once
  - reset everything to defaults
- **Number exports** — stops files being overwritten. Exports are saved as `image.png`, `image_1.png`, `image_2.png`, and so on.
- **File name templates** — use `{name}`, `{date}`, `{time}` or `{n}` in the file name to build names automatically.
- **Title bar button** — a FlattenSave button on Paint.NET's title bar shows or hides the panel in one click.
- **Resizable panel** — drag any edge or corner. The Flatten & Save button always stays visible, and the panel remembers its size and position.
- **Update check** *(optional)* — FlattenSave can tell you when a new version is available. It asks the first time you run it, and nothing is downloaded or installed automatically.

### Improved
- The version number in the corner is now a link to the FlattenSave GitHub page.
- Matches Paint.NET's Blue theme and its stock look more closely.

## 1.0.2

### Added
- **Plugin icon** in the panel header, to the left of the title.
- **Menu icon** on the Effects > Tools entry.
- **Theme support** — the panel follows Paint.NET's selected theme (light or dark) and switches live without a restart.

### Added
