# Changelog

All notable changes to [FlattenSave](https://github.com/donajello/FlattenSave).

## 1.0.2

### Added
- Plugin icon in the panel header, to the left of the title.
- Plugin icon on the Effects > Tools menu entry.
- The panel now follows Paint.NET's selected theme (light or dark) and switches live without a restart. A new light palette was added alongside the existing dark one.

### Changed
- Updated the README (icon header, theme support) and the landing page download text.
- Refreshed the README screenshot to show the header icon and new version.
- Removed the extra warning dialog when exporting with no file name; the inline message is shown instead.

## 1.0.1
- Version number shown in the panel.
